# VastAI

A personal ChatGPT-style AI assistant that runs entirely in the browser. Free to host on GitHub Pages, powered by open models through Groq's free API tier.

## Features
- Code panel like Claude/ChatGPT: watch code being written live, then preview websites (HTML, React, SVG) instantly
- Image understanding via Gemini free tier (optional key)
- Streaming replies with markdown, tables and syntax-highlighted code (copy button)
- Multiple chats with history saved in your browser, search, rename, delete
- Auto-generated chat titles
- Model picker (loads the models available on your Groq account)
- Attach images, PDFs, documents and code files for the AI to read
- Creates real downloadable PowerPoint, Word, Excel and PDF files with live preview
- Web search with sources (Groq built-in browser search on gpt-oss models)
- Voice: speak your message (Whisper) and hear replies read aloud
- Image generation (Pollinations, free, no key)
- Memory: VastAI remembers facts about you across chats (view/edit in Memory)
- Projects: group chats with shared instructions and files
- Export any chat as Markdown, PDF or Word
- Installable as an app on desktop and phone (PWA)
- Custom instructions (system prompt) and creativity control
- Stop and regenerate responses
- Dark and light theme, mobile responsive

## Setup
1. Get a free API key at console.groq.com
2. (Optional, for images) Get a free Gemini key at aistudio.google.com
3. Open the site, click **Settings**, paste the key, click **Save**

Your API key and chats are stored only in your browser's localStorage. Nothing is in this code.
