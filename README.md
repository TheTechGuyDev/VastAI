# VastAI

A personal ChatGPT-style AI assistant that runs entirely in the browser. Free to host on GitHub Pages, powered by open models through Groq's free API tier.

## Features
- Streaming replies with markdown, tables and syntax-highlighted code (copy button)
- Multiple chats with history saved in your browser, search, rename, delete
- Auto-generated chat titles
- Model picker (loads the models available on your Groq account)
- Attach text, code and PDF files for the AI to read
- Custom instructions (system prompt) and creativity control
- Stop and regenerate responses
- Dark and light theme, mobile responsive

## Setup
1. Get a free API key at console.groq.com
2. Open the site, click **Settings**, paste the key, click **Save**

Your API key and chats are stored only in your browser's localStorage. Nothing is in this code.
